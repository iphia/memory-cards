# 다섯 번 · 암기 카드

설치나 빌드가 필요 없는 GitHub Pages용 웹앱입니다. `index.html`을 열면 바로 사용할 수 있습니다.

## 사용 방법
- 예시 키워드 묶음: **임병찬-독립의군부**, **박상진-대한광복회**
- 한 카드에 `A-B-C-D-E`를 입력하면 하나가 무작위 문제로 선택됩니다. 예: 문제 B → 정답 A, C, D, E. 정답에는 선택된 키워드를 제외한 나머지가 입력 순서대로 표시됩니다.
- 키워드는 `-` 또는 줄바꿈으로 구분해 2~200개 입력합니다. 하이픈이 포함된 키워드는 한 줄에 하나씩 입력하세요. 빈 키워드와 중복 키워드는 입력할 수 없습니다.
- 정답을 보거나 가릴 때는 문제 키워드가 바뀌지 않습니다. 카드 이동이나 다음 바퀴, 새로고침 때 다시 무작위로 선택합니다. 이전과 같은 키워드가 나올 수도 있습니다.
- 정답 횟수는 키워드별이 아닌 카드 묶음 단위로 기록됩니다.
- 카드를 누르면 정답이 나타나고, 다시 누르면 가려집니다. 정답을 확인한 뒤 O 또는 X를 누릅니다.
- O를 누르면 현재 정답 횟수와 누적 정답 횟수가 각각 1 증가합니다. 5회 이상이어도 카드는 계속 표시됩니다.
- 마지막으로 O를 누른 시점부터 24시간마다 현재 정답 횟수가 1 감소하며 최솟값은 0입니다. O를 다시 누르면 감소 시점은 그때부터 24시간 뒤로 갱신됩니다. X와 카드 이동은 이 시점을 바꾸지 않습니다.
- 앱을 닫아 둔 동안에도 경과한 24시간 단위만큼 다음 접속 시 반영합니다. 누적 정답 횟수는 감소하지 않습니다. 진행 막대는 5회를 목표로 표시하며 현재 정답 횟수는 5회를 넘어서도 증가할 수 있습니다.
- 학습 가능한 카드를 한 바퀴 돌면 Fisher–Yates 방식으로 순서를 무작위로 섞습니다. 우연히 이전과 같은 순서가 나올 수 있습니다.
- 이전·다음 버튼으로 채점 없이 카드를 이동할 수 있습니다. 이동하면 정답은 가려지고 정답 횟수는 변하지 않습니다. 첫 카드에서는 이전 버튼을 누를 수 없습니다. 마지막 카드에서는 다음 바퀴 버튼으로 순서를 섞고 새 바퀴를 시작합니다.
- 기존 기록이 있어도 박상진 예시가 한 번 추가됩니다. 삭제한 예시는 다시 추가되지 않습니다.
- 카드 관리의 검색창에 입력하면 모든 키워드에서 실시간으로 검색합니다. 영문 대소문자는 구분하지 않으며 검색어를 지우면 전체 카드가 표시됩니다.
- 카드 관리를 통해 내용을 추가·수정·삭제할 수 있습니다. 목록의 수정 버튼을 누른 뒤 위 입력란에서 키워드를 바꾸고 수정 저장을 누르세요. 수정 취소도 가능하며, 수정 시 정답 횟수와 다음 감소 시각은 유지됩니다. 삭제하면 해당 학습 기록도 삭제됩니다.
- 정답 보기: Enter / Space, 채점: O / X.
- 기록은 현재 브라우저의 localStorage에 저장됩니다. 다른 기기·브라우저나 로컬 파일과 배포 사이트 사이에서는 공유되지 않습니다. 브라우저 데이터를 지우면 기록도 지워집니다.

## GitHub Pages에 올리기
1. GitHub에서 새 **Public** 저장소를 만듭니다. 예: `memory-cards`.
2. **Add file → Upload files**로 `index.html`, `style.css`, `app.js`를 저장소 최상위에 올리고 Commit changes를 누릅니다. 폴더 자체가 아닌 폴더 안의 파일을 업로드하세요.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. Source: **Deploy from a branch**, Branch: **main**, 폴더: **/(root)** 를 선택하고 Save를 누릅니다.
5. 배포가 끝나면 같은 화면의 Visit site에서 접속합니다. 일반적인 주소는 `https://계정이름.github.io/memory-cards/`입니다.

공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 구성
- `index.html`: 한국어 화면
- `style.css`: 모바일·데스크톱 반응형 스타일
- `app.js`: 카드, 채점, 저장, 복습 시간과 무작위 순서 관리

외부 라이브러리와 서버가 필요하지 않습니다. 공개 저장소에 올린 소스의 예시 내용은 공개됩니다. 앱 화면에서 직접 추가한 내용은 현재 브라우저에만 저장됩니다.

## 백업 및 복원
- 카드 관리 → 백업 다운로드: 모든 키워드 묶음, 정답·오답 횟수, 다음 정답 횟수 감소 시각, 카드 순서와 현재 위치를 JSON 파일로 저장합니다. 저장하지 않은 입력 내용은 포함되지 않습니다.
- 카드 관리 → 백업 파일 복원: 이 앱에서 받은 JSON 파일(최대 10MB)을 선택하고 덮어쓰기를 확인합니다. 현재 데이터는 합쳐지지 않고 교체됩니다. 필요하면 먼저 현재 데이터를 백업하세요.
- 다른 기기에서도 백업 파일을 선택해 기록을 옮길 수 있습니다. 자동 동기화는 아닙니다.
- 복원 시 다음 감소 시각을 유지하고, 파일을 보관한 동안 지난 24시간 단위도 반영합니다. 이전 버전의 백업도 복원할 수 있습니다.
- 파일 형식이 잘못되었거나 복원을 취소하거나 저장에 실패하면 기존 기록은 유지됩니다.

## 클립보드에서 여러 카드 추가
카드 관리 → 클립보드에서 추가를 누르면 복사한 내용을 읽어 미리 보여줍니다. 추가할 개수와 내용을 확인한 후 **N개 추가**를 눌러 저장합니다. 취소하면 추가되지 않습니다.

예: `윌슨-민족자결주의/이봉창-윤봉길-한인애국단/김원봉-신채호-의열단` → 카드 3개. `/`는 카드 구분자이며 각 카드 안의 `-`는 키워드 구분자입니다. 쉼표는 분리하지 않습니다. `/`나 `-`가 들어가는 키워드는 추가·수정 탭에서 한 줄에 하나씩 입력하세요.

브라우저에서 클립보드 읽기를 지원하지 않거나 권한이 거부되면 직접 붙여넣기 입력란을 사용할 수 있습니다. 한 번에 최대 200개·100,000자까지 처리하며, 형식이 잘못된 항목이 있으면 수정 후 다시 확인해야 합니다. 기존 카드와 학습 기록은 유지되며 같은 내용도 새 카드로 추가됩니다.

## 카드 관리 탭
카드 관리 기능은 목록·검색, 추가·수정, 여러 카드 추가, 백업·복원 탭으로 나뉩니다. 목록·검색 탭에서 카드별 현재 정답 횟수와 5회 목표 진행도, 누적 정답 횟수, 학습 상태와 다음 감소 시각을 함께 확인할 수 있습니다. 검색 결과에도 같은 진행도가 표시됩니다. 목록에서 수정을 누르면 추가·수정 탭이 열립니다. 탭을 바꿔도 입력 중인 내용은 유지됩니다. 탭에 초점이 있을 때 좌우 화살표 또는 Home/End로 이동할 수 있습니다.

## 이전 학습 기록 전환
기존 카드와 누적 정답 기록을 유지합니다. 이전에 쉬던 카드는 즉시 학습할 수 있으며, 기존 복습 예정 시각을 첫 감소 시각으로 사용합니다. 과거 정답 시각이 저장되지 않은 카드는 업데이트 후 첫 실행부터 24시간 뒤에 감소를 시작합니다.

기존 질문·정답 카드는 두 키워드 카드로 자동 전환됩니다. 기존 텍스트 안의 쉼표·하이픈은 추가 분리하지 않습니다. 카드 ID, 정답·오답 횟수와 감소 시각을 유지하며, 이전 버전(1·2) 백업도 같은 방식으로 복원합니다. 새 백업은 버전 3 형식으로 저장됩니다.

몇 번째 바퀴인지는 표시하거나 저장하지 않습니다. 카드 목록의 끝에 도달하면 순서를 무작위로 섞고 이어서 학습합니다.

카드 목록 끝에서 다음 카드로 이동하거나 채점하면, 순서를 섞으며 짧은 카드 애니메이션을 재생합니다. 일반 카드 이동이나 정답 표시에는 재생하지 않습니다. 기기의 동작 줄이기 설정이 켜져 있으면 애니메이션을 생략합니다.
